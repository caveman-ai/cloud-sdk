`caveman-sdk` is a zero-dependency (stdlib-only) Python 3.13+ SDK imported as `caveman_cloud`.

## Install

```bash
pip install caveman-sdk
```

## Unified client

```python
from caveman_cloud import Caveman

cv = Caveman()  # reads CAVEMAN_API_KEY or CAVE_TOKEN

models = cv.inference.models()
hits = cv.drives.drive("knowledge").grep({"pattern": "SLA"})
secrets = cv.secrets.list()  # metadata only, never values
rooms = cv.rooms.list()
credits = cv.credits.get()
```

All ten Cloud primitives are exposed on the same client instance (`inference`, `agents`, `sessions`, `sandboxes`, `drives`, `connectors`, `secrets`, `rooms`, `apps`, `evals`, `approvals`, `credits`).
