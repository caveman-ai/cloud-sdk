`caveman-ai/cloud-sdk` is the public developer surface for Caveman Cloud: the unified TypeScript (`@caveman-ai/sdk`), Python (`caveman-sdk`), and Go (`github.com/caveman-ai/sdk-go`) SDKs, the `cvm` CLI (`@caveman-ai/cloud`), `caveman-drive-mount`, and official Cloud skills.

Authoring an agent in TypeScript locally or embedding Harness v4? Start with [caveman-ai/agent-sdk](https://github.com/caveman-ai/agent-sdk).

## Install

```bash
npm install @caveman-ai/sdk
npm install -g @caveman-ai/cloud
pip install caveman-sdk
go get github.com/caveman-ai/sdk-go
```

## One key, one balance, ten primitives

Set `CAVEMAN_API_KEY` (or run `cvm login` for interactive CLI use). One unified `Caveman` client reaches Inference, Agents, Sessions, Sandboxes, Drives, Connectors, Secrets, Rooms, Apps, Evals, Approvals, and Credits.

```ts
import { Caveman } from "@caveman-ai/sdk";

const cv = new Caveman();
const models = await cv.inference.models();
const hits = await cv.drives.drive("knowledge").grep({ pattern: "refund" });
```
