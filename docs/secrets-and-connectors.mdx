Connectors and Secrets are strictly separate security primitives.

- **Connectors** hold team-authenticated SaaS and MCP OAuth identities with pinned tool catalogs, effect labels (`read`, `write`, `external`), and per-deployment grants. Underlying OAuth tokens never enter a Sandbox.
- **Secrets** hold KMS-encrypted raw credentials (`STRIPE_KEY`, `NPM_TOKEN`, `DB_URL`) scoped to an organization, repository, agent, or environment. Secrets are write-only and injected per command at the execution boundary.

## Use from the unified SDK

```ts
import { Caveman } from "@caveman-ai/sdk";

const cv = new Caveman();

// Connectors
const connectors = await cv.connectors.list();
await cv.connectors.grant("github", { deployment: "pr-reviewer", ceiling: "read" });

// Secrets (write-only: list returns metadata only, never values)
await cv.secrets.set({ name: "STRIPE_KEY", value: process.env.STRIPE_KEY!, environment: "production" });
const metadata = await cv.secrets.list();
```
