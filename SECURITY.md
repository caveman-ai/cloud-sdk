# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately rather than opening a public GitHub issue.

- **Email:** `security@caveman.so`
- **What to include:** affected package and version, minimal reproduction steps, and potential impact.

We acknowledge security reports within 2 business days and coordinate disclosure once a fix is released.

## Scope

This policy covers all packages published from `caveman-ai/cloud-sdk`:
`@caveman-ai/cloud` (`cvm`), `@caveman-ai/sdk`, `@caveman-ai/router-claude-code`,
`caveman-sdk` (Python), `github.com/caveman-ai/sdk-go`, and bundled skills.
